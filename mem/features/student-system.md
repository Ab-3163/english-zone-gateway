# Student System

## Auto Student ID
Format: `EZ-YYYY-NNNN` (e.g., EZ-2026-0001). Generated by `public.generate_student_id()` using sequence `student_id_seq`.

## Student Auth (passwordless)
- Login via `Student ID + phone` only
- Verified by SECURITY DEFINER RPC `get_student_by_credentials(_student_id, _phone)`
- Session kept in `sessionStorage` under key `student_session`
- Routes: `/student-register`, `/student-login`, `/student-portal`

## Admin Login Simplification
- Single form: email + numeric code (4-6 digits)
- Master code `1739` bypasses email OTP for any pre-existing admin email
- Master code does NOT auto-create users — only existing admins in `user_roles` can use it
- Edge function: `verify-otp` (modified)

## Payment Receipts
- Private storage bucket `payment-receipts`
- Public can insert, only admins can read/delete
- Receipts viewable in admin via signed URLs (5-min expiry)

## Admin Notifications
- Edge function `notify-admin-registration` fires on new student registration
- Sends email via Resend to all users with `admin` role
- Also logs into `admin_notifications` table
- From: `ÉLITE ZONE <onboarding@resend.dev>` (replace with verified domain when set up)

## Tables
- `students` (main) — RLS: public INSERT, admin SELECT/UPDATE/DELETE; reads via RPC only
- `admin_notifications` — admin-only
